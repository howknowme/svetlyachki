# Светлячки для Android: как выпустить в Google Play

Здесь лежит готовый Android-проект игры. Игра работает без интернета, в ней есть реклама AdMob, а иконка, обложка, скриншоты и текст для магазина уже сделаны.

## Что важно знать заранее

1. **Аккаунт разработчика оформляет взрослый.** Google Play Console и AdMob требуют возраст 18+. Регистрировать аккаунт и получать деньги с рекламы будет мама (или другой взрослый). Взнос $25 платится один раз.
2. **Новый личный аккаунт сначала проходит закрытый тест.** Google требует, чтобы игру установили минимум 12 тестировщиков и пользовались ей 14 дней подряд. Только после этого откроется кнопка выпуска для всех. Зови друзей и родных заранее.
3. **Сейчас в проекте тестовая реклама.** Деньги она не приносит. Свои id ты получишь в AdMob (шаг 4).
4. **Ключ подписи хранится в папке `KEEP-SECRET`.** Никому его не показывай и не выкладывай. Без него нельзя выпускать обновления. Сделай копию на флешку или в облако.

## Шаг 1. Собрать игру (.aab) через GitHub, без установки Android Studio

1. Создай на github.com **приватный** репозиторий, например `svetlyachki`.
2. Загрузи в него всё из этой папки, **кроме** `KEEP-SECRET` и `node_modules` (файл `.gitignore` уже их исключает).
3. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret** и добавь 4 секрета:
   - `KEYSTORE_BASE64`: всё содержимое файла `KEEP-SECRET/KEYSTORE_BASE64.txt`
   - `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`: значения из `KEEP-SECRET/passwords.txt`
4. Открой вкладку **Actions → Android build → Run workflow**. Через 5–10 минут внизу страницы сборки появится архив с файлами `app-release.aab` (для Google Play) и `app-release.apk` (поставить на свой телефон и проверить).

Можно и на компьютере: установи Android Studio и Node.js, затем в этой папке выполни `npm install`, `npm run sync` и открой папку `android` в Android Studio (Build → Generate Signed Bundle).

## Шаг 2. Google Play Console

1. Зарегистрируйся на play.google.com/console, оплати $25 и подтверди личность.
2. **Создать приложение:** название «Светлячки: блок-пазл», язык русский, тип «Игра», «Бесплатно».
3. **Страница в магазине:** тексты возьми из `store/store-listing.md`, картинки из папки `store` (иконка `icon-512.png`, обложка `feature-graphic-1024x500.png`, скриншоты `screenshot-*.png`).
4. **Политика конфиденциальности:** нужна ссылка. Проще всего включить GitHub Pages для репозитория (Settings → Pages → ветка `main`, папка `/docs`). Ссылка будет вида `https://ТВОЙ-НИК.github.io/svetlyachki/privacy.html`.
5. **Содержание приложения** (Policy → App content):
   - Реклама: **да, есть реклама**.
   - Целевая аудитория: советую **13–15, 16–17, 18+**. Если отметить детей младше 13, включатся строгие правила Google для детских приложений (Families), и рекламу придётся перенастраивать.
   - Возрастной рейтинг: заполни анкету IARC. Насилия, азартных игр и чатов нет, так что выйдет рейтинг «для всех».
   - Безопасность данных: «Данные собираются: да» → «Идентификаторы устройства или другие идентификаторы» (рекламный id), «Сведения о приложении и его производительности» (диагностика), цель: реклама и аналитика, передаются Google AdMob, шифруются при передаче. Аккаунтов и личных данных нет.
6. **Тестирование → Закрытое тестирование:** загрузи `app-release.aab`, добавь почты 12+ тестировщиков, отправь на проверку. Через 14 дней подай заявку на выпуск в «Рабочую версию».

## Шаг 3. Обновления

Поменял игру? Скопируй новую страницу в `game/index.html` и снова запусти **Run workflow**. Номер версии увеличится сам. Загрузи новый `.aab` в Play Console.

## Шаг 4. Включить настоящую рекламу (чтобы капали деньги)

1. Зарегистрируйся на admob.google.com (тоже взрослый аккаунт, туда приходят выплаты).
2. Добавь приложение (Android, «Светлячки»), затем создай два рекламных блока: **«С вознаграждением»** и **«Межстраничный»**.
3. Впиши свои id в `ads.json`: `appId` (вида `ca-app-pub-…~…`), `rewarded`, `interstitial` (вида `ca-app-pub-…/…`), и поставь `"testing": false`.
4. В AdMob → Конфиденциальность и сообщения создай сообщение GDPR (для Европы): игра сама покажет окно согласия.
5. Пересобери игру (шаг 1) и загрузи новую версию.

Пока игра на твоём телефоне в разработке, оставляй `testing: true`: клики по своей настоящей рекламе Google считает обманом и может заблокировать аккаунт.

### Как устроена реклама в игре
- Видео за бонус: когда кончились бомбы, отмены, смены фигурок или повороты, игра предлагает посмотреть видео. Только по желанию.
- Короткая реклама между ночами: не раньше 4-й ночи и не чаще, чем раз в две ночи. Посреди хода реклама не появляется.
- В «Ночи дня» рекламы нет.

## Что где лежит
- `game/index.html`: сама игра (та же, что по ссылке на claude.ai).
- `www/`: то, что попадает в приложение (собирается скриптом `scripts/build-www.py`, шрифты внутри, интернет не нужен).
- `android/`: Android-проект (Capacitor 8).
- `ads.json`: id рекламы.
- `store/`: иконка, обложка, скриншоты и тексты для магазина.
- `docs/privacy.html`: политика конфиденциальности.
- `.github/workflows/android.yml`: автосборка.
- `KEEP-SECRET/`: ключ подписи и пароли. **Не загружай на GitHub.**
